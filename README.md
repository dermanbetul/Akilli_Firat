# 🧠 Akıllı Fırat
Çocuklar için geliştirilmiş eğlenceli bir nesne tahmin oyunudur.

## 🎮 Proje Hakkında

Akıllı Fırat, kullanıcının aklından tuttuğu nesneyi çeşitli sorular sorarak tahmin etmeye çalışır.

Oyuncu sorulara "Evet" veya "Hayır" şeklinde cevap verir. Verilen cevaplara göre olası nesneler azaltılır ve oyun sonunda Akıllı Fırat tahminini yapar.

## ✨ Özellikler

- 🧠 Nesne tahmini
- ❓ Evet / Hayır soruları
- 🎯 Olasılıkları azaltarak tahmin yapma
- 😄 Eğlenceli kullanıcı deneyimi
- 🧩 Yeni nesneler için geliştirilebilir yapı
  
## 🛠️ Kullanılan Teknolojiler

- Python
- JavaScript
- HTML
- CSS

## 🚀 Amaç

Teknolojiyi eğlenceli ve etkileşimli bir oyun aracılığıyla insanlarla buluşturmak.
